- The_Adventurer.glb (modelo masculino conservado)

Para GitHub Pages: subir/reemplazar estos TRES archivos en la raíz del repositorio matar-o-morir. Mantener exactamente esos nombres. Luego esperar a que GitHub Pages publique y recargar la página.

Esta optimización reduce resolución de renderizado en pantallas de alta densidad, baja el mapa de sombras y pausa el render cuando la pestaña está oculta. Los modelos GLB fueron optimizados en sus texturas; no se modificó el contenido visible intencionalmente.

Importante: esto es una versión WEB para probar en GitHub Pages, NO es un APK nuevo. No borres la APK original que ya funciona.
